### Hola, soy Fernando Silva

Senior Full Stack Developer con más de 10 años de experiencia construyendo, manteniendo y evolucionando aplicaciones web, SaaS B2B, integraciones y herramientas internas de negocio.

Trabajo principalmente con PHP/Laravel, Vue.js, React, .NET/C#, ASP.NET, APIs REST, MySQL/PostgreSQL, Linux y Git. Me enfoco en crear software mantenible, resolver problemas reales de negocio y evolucionar sistemas existentes con criterio técnico.

Actualmente desarrollo Synapsale, una plataforma SaaS B2B de ventas con IA, donde participo en arquitectura, backend, frontend, workflows multicanal, integraciones externas y automatización con OpenAI API.

### Qué hago

- Desarrollo full stack en PHP/Laravel, Vue.js, React y .NET.
- Backend, APIs REST, integraciones entre sistemas, CRMs y herramientas de negocio.
- Frontend para aplicaciones internas, dashboards y producto SaaS B2B.
- Mantenimiento evolutivo, refactorización, debugging y resolución de incidencias.
- Automatización con IA aplicada a procesos comerciales y operativos.
